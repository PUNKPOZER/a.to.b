# SELECTOR

Автономный DJ-инструмент для анализа треков и подбора похожих: BPM, тональность
(Camelot), жанр, ритм/бас/энергия/текстура — весь анализ считается прямо в
браузере, без сервера и без сети.

Живая версия (пока приватная, для теста): https://claude.ai/artifact/FaqmCQNRS4ENkvtS5mA3FV

## Что внутри

- **Analyze** — перетаскиваешь трек или целую папку с музыкой (MP3, WAV, AIFF,
  FLAC, M4A), приложение анализирует BPM, тональность, жанр, ритмический
  профиль и показывает похожие треки из твоей библиотеки с разбивкой по
  критериям ("Why?").
- **Library** — личная библиотека проанализированных треков с фильтрами
  (BPM/жанр/энергия), дедупликацией по хэшу файла, кнопкой "Similar" —
  посмотреть, с чем схож любой трек из библиотеки.
- **Set Builder** — сборка сета из треков библиотеки с оценкой перехода
  между соседними треками (BPM, Camelot-совместимость, дельта энергии).
- **Sets** — сохранённые сеты.
- **Settings** — настройка весов similarity-движка и DJ Compatibility
  (степ-контролы + быстрые пресеты).

## Как запустить

Это один самодостаточный HTML-файл — открой `index.html` в браузере (Chrome/
Edge/Firefox с поддержкой Web Audio API). Ничего устанавливать не нужно:

```
# любой локальный сервер подойдёт, например:
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

Можно и просто открыть `index.html` двойным кликом — работает и без сервера.

## Как это устроено

Весь DSP-анализ (FFT, автокорреляция для BPM, алгоритм Крамхансла-Шмуклера
для тональности, детекция жанра по признакам, similarity-движок) написан на
чистом JavaScript и работает через Web Audio API — библиотек и бэкенда нет.
Данные библиотеки и сетов хранятся в `localStorage` браузера (только на
твоём устройстве, никуда не отправляются).

Похожесть треков считается не по одному признаку (типа "одинаковый BPM"), а
по взвешенной сумме нескольких групп признаков (темп, жанр, ритм, бас,
мелодия, гармония, энергия, текстура) с учётом кратности BPM (double/half
time) и совместимости тональностей по кругу Камелота. Всё, что не
анализируется по-настоящему, помечается как "unknown", а не выдумывается.
