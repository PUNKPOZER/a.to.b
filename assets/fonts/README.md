# ABC Areal (Dinamo)

The font binaries (`*.ttf`) in this folder are **not committed to git** (see `.gitignore`): ABC Areal is a commercial
typeface and its licence for web redistribution (GitHub Pages) has not been confirmed.
Copy the six static files here locally — `ABCAreal-Regular/Medium/Bold` + their `Italic` variants — and NOESIS will use them.
Without them the interface falls back to a neutral system sans-serif stack (see `--font-sans` in `ui/noesis.css`).
